# Capitix

A modular business platform: independently useful finance, supply chain, commercial, operations, and people modules that interact only through versioned APIs and events.

| Repository | Purpose |
|---|---|
| [architecture](https://github.com/capitix/architecture) | Architecture, decision records, and specifications |
| [platform](https://github.com/capitix/platform) | All modules, foundation services, platform services, contracts, and the shared infrastructure kit |
| [localization](https://github.com/capitix/localization) | Localization packs by owner and jurisdiction |
| [infrastructure](https://github.com/capitix/infrastructure) | Infrastructure as code for cells and environments |
